LAIXEHUNGTHICH - phiên bản nền quản trị

1. Website học viên: thi-a1/index.html
2. Quản trị: admin/index.html
3. supabase-schema.sql: tạo bảng dữ liệu trên Supabase.
4. supabase-config.js: điền SUPABASE_URL và SUPABASE_ANON_KEY.

Hiện admin có:
- Đăng nhập Supabase Auth khi đã cấu hình.
- Chọn đề.
- Sửa nội dung câu hỏi.
- Sửa đáp án.
- Chọn đáp án đúng.
- Đổi ảnh bằng đường dẫn.
- Thêm/xóa câu.
- Xuất/nhập toàn bộ JSON để sao lưu.

Nếu chưa cấu hình Supabase, admin chạy ở chế độ demo cục bộ và thay đổi không đồng bộ cho học viên.
